# RESTful API

This directory contains exercises focused on consuming, developing, securing, and documenting RESTful APIs using command-line tools and Python.

## Topics

- HTTP and HTTPS
- HTTP requests and responses
- HTTP methods and status codes
- Consuming APIs using `curl`
- Sending HTTP requests using Python's `requests` library
- Parsing and processing JSON data
- Exporting API data to CSV
- Developing APIs using Python's `http.server` module
- Developing RESTful APIs using Flask
- API endpoints, routing, and request handling
- Handling GET and POST requests
- API security and authentication
- Basic authentication and password hashing
- JSON Web Tokens (JWT)
- Authorization and role-based access control
- API standards and documentation with OpenAPI

## Files and Description

| **File** | **Description** |
| -------- | --------------- |
| `task_02_requests.py` | Consumes data from an API using Python's `requests` library, prints post titles, and saves post data to a CSV file. |
| `task_03_http_server.py` | Develops a simple API using Python's built-in `http.server` module, with endpoints that return text and JSON responses. |
| `task_04_flask.py` | Develops a Flask API with routes for retrieving user data and adding users through POST requests. |
| `task_05_basic_security.py` | Implements API security using basic authentication, JWT authentication, and role-based access control. |
