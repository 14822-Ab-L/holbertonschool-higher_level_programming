# Python - Server-Side Rendering

This directory contains Python exercises focused on server-side rendering (SSR) using Flask and the Jinja templating engine. The activities cover generating files from templates, building Flask web applications, rendering dynamic HTML, handling data from JSON and CSV files, and retrieving product information from SQLite databases.

## Topics

- Server-side rendering (SSR)
- Client-side rendering vs. server-side rendering
- Python string templating and placeholder replacement
- File reading and writing
- Input validation and error handling
- Flask web framework
- HTTP routes and request handling
- HTML templates and rendering
- Jinja templating engine
- Reusable template components
- Template inclusion and inheritance
- Dynamic content rendering using loops and conditionals
- Reading and parsing JSON files
- Reading and parsing CSV files
- URL query parameters
- Filtering data by ID
- SQLite databases and SQL queries
- Integrating multiple data sources into web applications

## Files and Description

| **File** | **Description** |
|---|---|
| `task_00_intro.py` | Generates personalized invitation files from a template and attendee data, handling missing values, invalid inputs, and empty data. |
| `task_01_jinja.py` | Creates a Flask application with multiple routes and HTML templates using Jinja, including reusable header and footer components. |
| `task_02_logic.py` | Renders dynamic content in Flask using Jinja loops and conditionals, loading item data from a JSON file. |
| `task_03_files.py` | Displays product information from JSON or CSV files, supporting filtering by product ID and handling invalid sources or missing products. |
| `task_04_db.py` | Extends product display functionality to retrieve data from a SQLite database alongside JSON and CSV sources. |
