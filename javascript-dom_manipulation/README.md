# JavaScript - DOM Manipulation

This directory contains introductory JavaScript exercises focused on interacting with and modifying HTML documents through the Document Object Model (DOM). The activities cover selecting HTML elements, changing styles and content, handling user events, dynamically creating elements, and retrieving data from external APIs using the Fetch API.

## Topics

- Introduction to the Document Object Model (DOM)
- Selecting HTML elements using `document.querySelector`
- Working with HTML elements, IDs, classes and tag names
- Modifying element styles and CSS classes
- Accessing and updating HTML element content
- Creating and inserting HTML elements dynamically
- Handling click events and user interactions
- Toggling CSS classes
- Making HTTP requests using the Fetch API
- Working with Promises and JSON responses
- Retrieving and displaying data from external APIs
- Using JavaScript without reloading the HTML page

## Files and Description

| **File** | **Description** |
|---|---|
| `0-script.js` | Changes the text colour of the `header` element to red. |
| `1-script.js` | Changes the `header` text colour to red when the user clicks an element with the ID `red_header`. |
| `2-script.js` | Adds the `red` CSS class to the `header` element when the user clicks an element with the ID `red_header`. |
| `3-script.js` | Toggles the `header` element between the `red` and `green` CSS classes when the user clicks an element with the ID `toggle_header`. |
| `4-script.js` | Dynamically creates and adds a new `li` element to a list when the user clicks an element with the ID `add_item`. |
| `5-script.js` | Updates the text content of the `header` element when the user clicks an element with the ID `update_header`. |
| `6-script.js` | Fetches a Star Wars character's name from the Star Wars API and displays it in the HTML document. |
| `7-script.js` | Fetches Star Wars movie data from the Star Wars API and displays the movie titles in a list. |
| `8-script.js` | Fetches a French translation of "hello" from an external API and displays it in the HTML document. |
