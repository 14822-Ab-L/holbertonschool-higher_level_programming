# Python - Serialization

This directory contains Python exercises focused on serializing and deserializing data using different formats.

## Topics

- Serialization and deserialization
- JSON
- Pickle
- CSV to JSON conversion
- XML
- Marshaling

## Files and Description

| **File**                         | **Description**                                                     |
| -------------------------------- | ------------------------------------------------------------------- |
| `task_00_basic_serialization.py` | Saves a Python dictionary to a JSON file and loads it back.         |
| `task_01_pickle.py`              | Serializes and deserializes a custom Python object using `pickle`.  |
| `task_02_csv.py`                 | Converts CSV data into JSON format.                                 |
| `task_03_xml.py`                 | Serializes a Python dictionary to XML and deserializes it back.     |
