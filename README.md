# Higher Level Programming

This repository contains projects focused on Python programming and data handling.

## Topics

-
- Python programming
- Serialization and deserialization
- JSON
- Pickle
- CSV
- XML
- Marshaling
- MySQL database connections
- Object-relational mapping (ORM)
- SQLAlchemy
- Database CRUD operations
- SQL injection prevention

## Directories

| **Directory**                      | **Description**                                                                 |
| ---------------------------------- | ------------------------------------------------------------------------------- |
| `python-serialization`             | Explores serialization and deserialization using JSON, pickle, CSV, and XML.    |
| `python-object_relational_mapping` | Explores connecting Python to MySQL databases using MySQLdb and SQLAlchemy ORM. |
