# Higher Level Programming

This repository contains projects focused on higher-level programming concepts using Python, including data handling, database management, object-relational mapping, and RESTful API development.

## Topics

- Python programming
- Serialization and deserialization
- JSON
- Pickle
- CSV
- XML
- Marshaling
- MySQL database connections
- Object-relational mapping (ORM)
- SQLAlchemy
- Database CRUD operations
- SQL injection prevention
- HTTP and HTTPS
- RESTful API development
- Consuming APIs using `curl` and Python `requests`
- API development using Python `http.server` and Flask
- API authentication and authorization
- Basic authentication and password hashing
- JSON Web Tokens (JWT)
- Role-based access control
- API documentation with OpenAPI

## Directories

| **Directory** | **Description** |
| ---------------------------------- | ------------------------------------------------------------------------------- |
| `python-serialization` | Explores serialization and deserialization using JSON, pickle, CSV, and XML. |
| `python-object_relational_mapping` | Explores connecting Python to MySQL databases using MySQLdb and SQLAlchemy ORM. |
| `restful-api` | Explores consuming, developing, securing, and documenting RESTful APIs using command-line tools and Python. |
