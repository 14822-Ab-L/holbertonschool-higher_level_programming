# JavaScript - Warm up

This directory contains introductory JavaScript exercises focused on fundamental programming concepts, scripting with Node.js, and basic manipulation of variables, arguments, loops, functions, and objects.

## Topics

- JavaScript syntax and scripting with Node.js
- Constants, variables, and data types
- Command-line arguments using `process.argv`
- Type conversion and integer parsing
- Conditional statements and program flow
- Loops (`for` and `while`)
- Arithmetic operators
- Functions and recursion
- Arrays and objects
- Object property manipulation
- Modules and exports
- Standard output using `console.log`

## Files and Description

| **File** | **Description** |
|---|---|
| `0-javascript_is_amazing.js` | Declares a constant and prints a message to the console. |
| `1-multi_languages.js` | Prints multiple messages using separate `console.log()` statements. |
| `2-arguments.js` | Prints a message depending on the number of command-line arguments provided. |
| `3-value_argument.js` | Prints the first argument passed to the script or a message if none is provided. |
| `4-concat.js` | Combines two arguments into a sentence. |
| `5-to_integer.js` | Converts the first argument to an integer and prints the result. |
| `6-multi_languages_loop.js` | Prints multiple messages using an array and a loop. |
| `7-multi_c.js` | Prints `C is fun` a specified number of times using a loop. |
| `8-square.js` | Prints a square of `X` characters based on a given size. |
| `9-add.js` | Defines a function to add two integers provided as arguments. |
| `10-factorial.js` | Calculates the factorial of an integer using recursion. |
| `11-second_biggest.js` | Finds and prints the second-largest integer among the command-line arguments. |
| `12-object.js` | Updates a property value in a JavaScript object. |
| `13-add.js` | Exports an addition function for use in other JavaScript files. |
